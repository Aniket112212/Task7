In this task, we built a simple Python script (or Jupyter Notebook) to:

Create a SQLite database (sales_data.db) with a sales table.

Insert sample sales data (products, quantities, prices).

Use SQL queries inside Python to:

Group data by product

Calculate total quantity sold and total revenue

Load the results into a Pandas DataFrame.

Print the summary in the console.

Visualize revenue by product using a Matplotlib bar chart.

🔍 Key Skills Demonstrated
SQLite integration in Python (sqlite3)

SQL query usage with GROUP BY and aggregation (SUM)

Data analysis with Pandas

Data visualization with Matplotlib
